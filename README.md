# Criando-um-Dashboard-de-Vendas-do-Xbox-com-Excel
Dashboard interativo de vendas do ecossistema Xbox desenvolvido no Excel. O projeto foca na transformação de dados brutos de assinaturas (Game Pass, EA Play, Minecraft) em insights visuais, utilizando Tabelas Dinâmicas, Segmentação de Dados e técnicas de UI Design para análise de faturamento e comportamento de renovação.
