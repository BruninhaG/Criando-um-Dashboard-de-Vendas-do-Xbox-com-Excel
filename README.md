# 🎮 Criando um Dashboard de Vendas do Xbox com Excel

Este projeto foi desenvolvido como parte de um desafio de curso, com o objetivo de transformar dados brutos de vendas em uma ferramenta visual interativa para tomada de decisões.

---
## 🚀 Tecnologias Utilizadas
* **Microsoft Excel**: Limpeza de dados, Tabelas Dinâmicas e Design de Dashboard.
* **Power Query**: (Se você usou para tratar os dados).
* **Git/GitHub**: Versionamento e portfólio.

## 📊 O Projeto
O dashboard analisa o desempenho de assinaturas (EA Play, Minecraft Pass e Xbox Game Pass), permitindo filtrar os resultados por tipo de recorrência (Anual, Mensal ou Trimestral).

### Principais Indicadores (KPIs):
* **Faturamento Total por Produto**: Cards destacados com valores consolidados.
* **Status de Renovação**: Gráfico de barras comparando clientes com renovação automática ativa vs. inativa.
* **Segmentação Dinâmica**: Filtros interativos para análise rápida.

---

## 🧠 O que aprendi:
1. Estruturação de dados em Tabelas Oficiais.
2. Criação de tabelas dinâmicas para resumir grandes volumes de dados.
3. Design de interface (UI) focada na experiência do usuário dentro do Excel.
4. Conexão de relatórios através de Segmentações de Dados (Slicers).
